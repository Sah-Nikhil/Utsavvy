# Utsavvy

Utsavvy is a GenAI planning assistant for weddings, birthdays and community events in India. Each event gets a shared canvas, where the assistant lays out the budget, timeline, vendor checklist and inspirations, and a chat, where everyone planning the event talks to each other and to the assistant.

Built for PromptWars Virtual.
