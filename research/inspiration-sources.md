# Inspiration sources for the Canvas (ticket 003)

Checked 21 October 2026. This is a build decision for a solo developer with about five build days. **Observation** means a source states the fact. **Inference** means the proposed product decision or a conclusion from those facts. No account, API key, device test, or paid call was used.

## Decision

**Inference.** Build one Inspiration item with a source type, the Member-provided or provider URL, attribution, and either a licensed image or a provider-controlled embed. Launch with Pexels search, Member uploads, prompt-generated images if billing is enabled, and URL references from Pinterest/Instagram. Pinterest URLs should render through Pinterest's official widget and link back. Do not download, cache, crop, recolor, analyze, or AI-remix Pinterest imagery. Reserve theme extraction and image remix for Member-owned/authorized images and carefully selected stock images. The evidence and risks follow.

## Pinterest

**Observation.** Pinterest requires a business account, verified email, acceptance of developer terms, an app request, and Pinterest approval even for Trial API access. Trial supports reading boards and Pins; Standard is intended for a public integration. Trial has a universal 1,000-request/day/app limit. Standard has a universal 100-request/second/user/app limit, with additional endpoint-category limits. Trial-created Pins and boards are visible only to their creator. A Standard request needs a prior Trial approval, public privacy policy, complete use-case description, and a video of a working integration that shows the OAuth flow. Pinterest says to allow **a few days** before following up about access status; it publishes no approval-time guarantee. New apps registered from 14 September 2026 can receive `PINNER_DATA_ACCESS_DENIED` for non-business user data without Pinterest authorization. [App setup](https://developers.pinterest.com/docs/getting-started/connect-app/), [access tiers](https://developers.pinterest.com/docs/key-concepts/access-tiers/), [rate limits](https://developers.pinterest.com/docs/reference/rate-limits/).

**Observation.** An approved app can request `boards:read` and `pins:read` via Pinterest OAuth 2.0. `GET /v5/boards`, `GET /v5/boards/{board_id}/pins`, and `GET /v5/pins` concern the authorized account's content; `GET /v5/search/pins` searches that account's Pins. This is not a general Pinterest discovery feed. `GET /v5/search/partner/pins?term=...` exists but Pinterest's published API collection labels it **beta, not available to all apps**, returning at most ten results. Its existence is not access for a new app. [OAuth scopes](https://developers.pinterest.com/docs/getting-started/set-up-authentication-and-authorization/), [List Pins](https://developers.pinterest.com/docs/api/v5/pins-list/), [Pinterest API collection](https://www.postman.com/pinterest/pinterest-collections/documentation/egt1crl/pinterest-rest-api-latest?entity=request-15933045-2e063e88-1aeb-4699-95ca-18e3f536b0dd).

**Observation.** Pinterest's developer guidelines prohibit storing information accessed through Pinterest developer materials, except specified campaign analytics; require fetching again when needed; and prohibit automated scraping and using Pinterest materials to train or develop AI models. For published Pinterest content, they require a clear source link, prohibit obscuring or filtering it, and prohibit creating new distributable content from Pins. A Pinterest URL does not transfer copyright ownership or remix rights. [Developer guidelines](https://policy.pinterest.com/en/developer-guidelines), [Pinterest terms](https://policy.pinterest.com/en/terms-of-service).

**Observation.** Official `pinit.js` widgets render an individual Pin from a full URL (`data-pin-do="embedPin"`) or a board (`data-pin-do="embedBoard"`, up to 50 Pins). Pinterest documents these as web features without an API application in the widget setup. A search of Pinterest's current web-feature documentation found no supported public oEmbed endpoint; legacy `/v3/pidgets/...` examples are outside the documented v5 API and should not be a dependency. [Widgets](https://developers.pinterest.com/docs/web-features/widgets/), [web add-ons](https://developers.pinterest.com/docs/web-features/add-ons-overview/), [API reference](https://developers.pinterest.com/docs/api/v5/pinterst/).

**Inference.** V1 accepts a pasted/shared Pinterest Pin or board URL, stores **the Member-supplied URL only**, and renders the official widget in a fixed reference card with an outbound link. Validate the host and path, resolve short URLs only to a Pinterest URL, and let `pinit.js` display the content. Do not fetch `og:image`, use `i.pinimg.com` as an app image, proxy/cache widget assets, or build a thumbnail from a Pinterest page: the official widget is the documented display route, and server-side extraction would conflict with the scraping/storage rules. A Pinterest reference may influence planning only through a Member's own written description (for example, "marigolds and saffron") or another image for which the Member has rights; do not feed Pinterest pixels to the Assistant for remix or palette extraction. This limits Canvas layout control but avoids API approval and derivative-content risk. [Widgets](https://developers.pinterest.com/docs/web-features/widgets/), [developer guidelines](https://policy.pinterest.com/en/developer-guidelines).

## Stock photo search

**Observation.** Unsplash's API starts in Demo at **50 JSON requests/hour**; Production approval raises that to **1,000/hour**. Public use should apply for Production with screenshots and compliance evidence. The API requires direct use of returned `images.unsplash.com` URLs to count views, attribution to both photographer and Unsplash with links/UTM parameters, and a call to `photo.links.download_location` when a Member selects a photo for placement on the Canvas (an action comparable to inserting an image). Unsplash's general license permits modification, but its **API terms direct AI/ML uses to Unsplash Data**, so API stock photos should not be routed into a model without a rights check or permission. [API documentation](https://unsplash.com/documentation), [Production guidance](https://help.unsplash.com/en/articles/3887917-when-should-i-apply-for-a-higher-rate-limit), [download events](https://help.unsplash.com/en/articles/2511258-guideline-triggering-a-download), [API attribution](https://help.unsplash.com/en/articles/2511315-guideline-attribution), [API terms](https://unsplash.com/api-terms).

**Observation.** Pexels provides a free API key with **200 requests/hour and 20,000/month**. Its help center currently says increases are paused. The API guidelines require a prominent Pexels link and ask for photographer credit where possible, even though the general Pexels license does not require attribution and allows modification. Its API returns display-ready `src` URLs; the documented guidelines do not impose Unsplash-style hotlinking or download-event calls. Pexels recommends caching API responses for about 24 hours. Its terms bar a competing stock library and large-scale extraction for AI training or dataset creation; a single Member-selected image edit is distinct from bulk training, but likeness and other third-party rights still matter. [API limits](https://help.pexels.com/hc/en-us/articles/47677890260761-Is-the-Pexels-API-free-to-use), [limit increases](https://help.pexels.com/hc/en-us/articles/900005852323-How-do-I-get-unlimited-requests), [API guidelines and image fields](https://www.pexels.com/api/documentation/), [cache advice](https://help.pexels.com/hc/en-us/articles/900006470063-What-steps-can-I-take-to-avoid-hitting-the-rate-limit), [license](https://www.pexels.com/license/), [AI/API terms](https://help.pexels.com/hc/en-us/articles/900005880463-What-are-the-Terms-and-Conditions).

**Observation, limited spot check.** Public search pages show actual Indian haldi photos, a decorated Ganesh idol, and a Durga Puja pandal photo. Searches for `indian wedding decor`, `haldi ceremony`, `mehndi decor`, `sangeet`, `ganesh puja`, `durga puja`, and `indian birthday` return pages on Pexels or Unsplash. In the inspected results, ritual/people pictures are easier to find than precise decor layouts; Ganesh and Durga images often show idols or processions rather than a society-event setup. Broad Pexels result counts mix related terms. These are **not API result counts or a measured relevance benchmark**. Pexels examples: [haldi photo](https://www.pexels.com/photo/close-up-of-a-prewedding-haldi-ceremony-where-feet-of-the-groom-are-covered-in-yellow-powder-14691580/), [Ganesh idol](https://www.pexels.com/photo/colorful-ganesh-idol-decorated-for-festival-33350746/), [Durga pandal photo](https://www.pexels.com/photo/vibrant-durga-puja-pandal-in-kolkata-35095727/), [Indian wedding decor search](https://www.pexels.com/search/indian%20wedding%20decor/), [Indian birthday search](https://www.pexels.com/search/indian%20%20birthday/). Unsplash examples: [Indian wedding decor search](https://unsplash.com/s/photos/indian-wedding-decor), [sangeet search](https://unsplash.com/s/photos/sangeet), [Ganesh Puja search](https://unsplash.com/s/photos/ganesh-puja), [community-event search](https://unsplash.com/s/photos/community-event).

**Inference.** Use **Pexels first** for v1 search: its default quota is four times Unsplash Demo, its licensing permits edits, and it has an immediate key request rather than a Production review dependency. Put photographer/Pexels attribution and a source link on every stock Inspiration. Keep searches narrow (`mehndi backdrop`, `marigold mandap`, `society Ganesh decoration`) and offer uploads/AI generation when exact local decor is absent. Use Unsplash later if its hotlink, attribution, placement tracking, and Production path fit the architecture. Do not market the Canvas as a stock photo library. [Pexels API](https://www.pexels.com/api/documentation/), [Pexels license](https://www.pexels.com/license/), [Unsplash documentation](https://unsplash.com/documentation).

## AI-generated Inspirations and remix

**Observation.** Google's current native image models include `gemini-nano-banana-2.1` (about **$0.0336** per 1K output), `gemini-3.1-flash-lite-image` (about **$0.0336** per 1K), `gemini-3.1-flash-image` (about **$0.067** per 1K), and `gemini-3-pro-image` (about **$0.134** per 1K/2K), plus input/text token charges. Their **Gemini API free tier for image generation is unavailable** in the pricing table. Google AI Studio can be free for experimentation, but that does not supply free image generation to a public app. `gemini-2.5-flash-image` shut down on **2 October 2026**; Imagen was deprecated and shut down on **17 August 2026**. [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing), [image generation guide](https://ai.google.dev/gemini-api/docs/image-generation), [AI Studio billing](https://ai.google.dev/gemini-api/docs/billing/).

**Observation.** Nano Banana models accept an input image and text instructions for editing/restyling; Google says generated images carry a SynthID watermark. Google's image guide requires rights to uploaded images. Its prohibited-use policy includes privacy/IP violations, non-consensual intimate imagery, and deceptive impersonation; a wedding or birthday photo can contain identifiable people, including children. [Image editing and SynthID](https://ai.google.dev/gemini-api/docs/image-generation), [Google policy](https://policies.google.com/terms/generative-ai/use-policy), [Gemini API terms](https://ai.google.dev/gemini-api/terms).

**Inference.** V1 can offer prompt-to-image plus "remix to this Event's theme" on AI-created assets and Member-owned/authorized uploads. Start with `gemini-3.1-flash-lite-image` for low-cost trials or `gemini-nano-banana-2.1` for stronger edits, with an explicit per-Event quota and billing enabled. Treat the listed output prices as estimates, since inputs and text add charges. Prefer decor-only crops or scenes when a photo shows identifiable people, and ask the Member to confirm rights before uploading/editing. Do not feed Pinterest or Instagram post images into the model. A comparable paid route is OpenAI's GPT Image API, which supports image edits but adds another provider and billing path; it offers no one-week build advantage here. [Google image guide](https://ai.google.dev/gemini-api/docs/image-generation), [Google pricing](https://ai.google.dev/gemini-api/docs/pricing), [OpenAI image guide](https://developers.openai.com/api/docs/guides/image-generation).

## Phone sharing and Instagram

**Observation.** An **installed** PWA can register one `share_target` in its manifest. It can receive title/text/link fields and, with multipart `POST`, files. Chrome's Android documentation notes that Android does **not** populate the Web Share Target `url` field, so links can arrive in `text`. Pinterest's help says its Android app can share a Pin or board link to a third-party app. Neither Pinterest nor Instagram publishes a stable promise of exact Android payload fields for this PWA. No live Android payload was captured in this research. [Chrome Web Share Target](https://developer.chrome.com/docs/capabilities/web-apis/web-share-target), [PWA integration](https://web.dev/learn/pwa/os-integration), [Pinterest sharing](https://help.pinterest.com/en-gb/article/send-pins-boards-and-profiles).

**Observation.** Meta lifted the token and App Review requirement for **public Instagram oEmbed** on **15 June 2026**. Its current documentation allows tokenless calls at **1,000 requests/hour/endpoint**; prior `Meta oEmbed Read` approval and an app token remain optional for a much higher quota. The endpoint returns embed HTML/basic technical data, not a license to download or edit Instagram media. This supersedes older guides saying a Meta app/token/review are mandatory for all Instagram embeds. [Meta Instagram oEmbed documentation](https://developers.facebook.com/documentation/instagram-platform/oembed), [Meta oEmbed announcement](https://developers.facebook.com/blog/post/2026/06/15/tokenless-access-to-meta-oembed-apis/).

**Inference.** Make the share landing route accept `text`, `title`, `url`, and optional `image/*` files; parse an allowed Pinterest/Instagram URL from the text, then let the Member choose the Event. For Instagram, store the link and render the provider embed only for public content; a link card is the fallback when private/deleted content cannot embed. Do not treat a social app's shared URL as a transferred image file or as permission to remix. Add a normal paste-URL and file-upload route for browsers without share target support. **Required device check before promising one-tap sharing:** install the PWA on an Android phone, share one Pinterest Pin, one board, one Instagram post, and one Reel, then record which fields and MIME types arrive. [Chrome Web Share Target](https://developer.chrome.com/docs/capabilities/web-apis/web-share-target), [Pinterest sharing](https://help.pinterest.com/en-gb/article/send-pins-boards-and-profiles), [Meta Instagram oEmbed reference](https://developers.facebook.com/docs/graph-api/reference/instagram-oembed/).

## Theme extraction

**Observation.** `node-vibrant` and Color Thief extract color palettes from image pixels in JavaScript. Browser canvas readback fails for a cross-origin image without CORS permission. Gemini can take an image and return text constrained by a JSON schema. [node-vibrant](https://github.com/Vibrant-Colors/node-vibrant), [Color Thief](https://github.com/lokesh/color-thief), [canvas CORS](https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/CORS_enabled_image), [Gemini image understanding](https://ai.google.dev/gemini-api/docs/image-understanding), [structured output](https://ai.google.dev/gemini-api/docs/structured-output).

**Inference.** Extract 3-5 palette hex codes locally from Member uploads, generated images, or stock images only when pixel access/CORS and source terms allow it. A multimodal call adds style and decor keywords (for example, `marigold`, `brass`, `pastel`), with a schema such as `{palette: string[], style: string, decorKeywords: string[]}` and Member editing before the theme feeds the plan. A palette algorithm cannot infer cultural context reliably from colors alone. For a Pinterest/Instagram reference, use the Member's typed description instead of image analysis. [Color Thief](https://github.com/lokesh/color-thief), [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output), [Pinterest developer guidelines](https://policy.pinterest.com/en/developer-guidelines).

## V1 cut and material risks

| Source | V1 Canvas route | Main risk / guard |
| --- | --- | --- |
| Pexels | Search, select, credited image and source link. | Relevance for specific Indian decor is uneven; use local query variants and uploads. Respect attribution and avoid a stock-library clone. [Pexels API](https://www.pexels.com/api/documentation/), [license](https://www.pexels.com/license/). |
| Member upload | Uploaded image, optional theme extraction and remix after rights confirmation. | Recognizable people and ownership; keep the action explicit. [Google policy](https://policies.google.com/terms/generative-ai/use-policy). |
| Gemini image | Generate or edit authorized image; label as AI-generated. | Paid API output and input charges, SynthID, safety filters; cap usage. [Pricing](https://ai.google.dev/gemini-api/docs/pricing), [image guide](https://ai.google.dev/gemini-api/docs/image-generation). |
| Pinterest | Paste/share URL; official Pin/board widget and link. | API review and terms block a reliable search/remix path for a one-week build. [Access tiers](https://developers.pinterest.com/docs/key-concepts/access-tiers/), [guidelines](https://policy.pinterest.com/en/developer-guidelines), [widgets](https://developers.pinterest.com/docs/web-features/widgets/). |
| Instagram | Paste/share URL; public oEmbed or link card. | Share payload varies; public embed can disappear, and embed rights do not grant remix rights. [Meta oEmbed](https://developers.facebook.com/docs/graph-api/reference/instagram-oembed/), [Chrome share target](https://developer.chrome.com/docs/capabilities/web-apis/web-share-target). |
| Unsplash | Defer API integration. | Production review, hotlinking, attribution, placement tracking, and AI-use terms cost build time. [API documentation](https://unsplash.com/documentation), [API terms](https://unsplash.com/api-terms). |

**Recommendation gist.** The product can truthfully promise "save a Pinterest reference on the Canvas" through an official embed. It should not promise "search all Pinterest" or "AI-remix a Pinterest image" in v1. Pexels and authorized uploads supply editable visual input; paid Gemini generation fills local-decor gaps. [Pinterest widgets](https://developers.pinterest.com/docs/web-features/widgets/), [Pinterest search collection](https://www.postman.com/pinterest/pinterest-collections/documentation/egt1crl/pinterest-rest-api-latest?entity=request-15933045-2e063e88-1aeb-4699-95ca-18e3f536b0dd), [Pinterest guidelines](https://policy.pinterest.com/en/developer-guidelines), [Pexels license](https://www.pexels.com/license/), [Gemini image guide](https://ai.google.dev/gemini-api/docs/image-generation).
