# Ticket 015: hosted Vendor discovery, site reading, and geocoding

Research date: 2026-10-21 (India). Scope: a Member asks the Assistant to discover Indian Vendors; the app saves Vendor cards from each Vendor's **own website** on an Event Canvas and stores Marker coordinates for a Leaflet/OpenStreetMap map. This is a documentation and terms review, not an account-level or live-query test. Prices are USD unless stated. "Observation" below means a provider or primary-source statement. "Inference" means the proposed application decision; it is not a legal clearance or measured India-quality result.

## Recommendation

**Use Serper organic web search for candidate URLs, a bounded server-side `fetch` plus HTML/JSON-LD parser for each Vendor's own site, and Geoapify Forward Geocoding for stored Marker coordinates.** Serper's 2,500-query trial covers the proposed 500 discovery queries without a card; its license permits downloading its materials for as long as the use case requires, subject to third-party rights. Geoapify permits production use on its free plan, 3,000 geocodes/day, persistent results with attribution, and display on the chosen OSM map. Keep Serper's Google SERP fields out of Vendor cards: independently read and cite the Vendor page. [Serper pricing](https://serper.dev/), [Serper terms](https://serper.dev/terms), [Geoapify pricing](https://www.geoapify.com/pricing/), [Geoapify geocoding terms](https://www.geoapify.com/geocoding-api/).

**Material risk:** Serper says it supplies "web-scraped data" and is not affiliated with Google; its license cannot grant rights to Google or third-party content. An organic URL used only to find the Vendor's own site is a narrower use than persisting Google's local-pack, Maps, review, image, or snippet data. SerpApi is another Google-SERP supplier and reports active litigation with Google, so this upstream risk is real, not resolved here. If that risk is unacceptable, use Brave Search API for transient candidate selection **only after obtaining storage rights or written confirmation that persisting independently verified Vendor URLs is permitted**; its standard terms explicitly forbid storing Search Results "in whole or in part." [Serper terms](https://serper.dev/terms), [SerpApi's account of litigation](https://serpapi.com/blog/google-v-serpapi-threatening-access-to-public-data/), [Brave API terms](https://api-dashboard.search.brave.com/documentation/resources/terms-of-service).

**Cost for 500 searches + 300 geocodes over development/demo:** $0 in published trial/free allowances if the 300 geocodes stay within Geoapify's 3,000-credit daily limit. Server fetching and parsing have no per-page API charge; Vercel function time and the chosen LLM's tokens are additional. If Serper's one-time trial is exhausted, its smallest listed top-up is $50 for 50,000 credits, not $0.50 pay-as-you-go. Geoapify's first paid plan is $59/month. [Serper pricing](https://serper.dev/), [Geoapify pricing](https://www.geoapify.com/pricing/), [Vercel function billing/limits](https://vercel.com/docs/functions/limitations).

India-specific relevance is **unmeasured** because this review made no paid calls, signups, or live vendor queries. Providers' localization controls are evidence of capability, not of accuracy. ## 2. Reading the Vendor's own site

**Observation.** RFC 9309 defines `robots.txt` for automatic clients and says a crawler must honor applicable allow/disallow rules. The Vendor site's own terms and access controls still matter; `robots.txt` is not a copyright license. [RFC 9309](https://www.rfc-editor.org/info/rfc9309/), [Indian Copyright Act, rights](https://copyright.gov.in/Copyright_Act_1957/chapter_iii.html).

**Inference.** For a Member-triggered search, identify the crawler in `User-Agent` with a contact URL/email, retrieve `/robots.txt` for the Vendor host, obey its matching rule, and use a conservative per-host queue (for example one request at a time, seconds apart). Limit the site to a handful of public home/about/services/pricing/contact pages; honor `429`, `403`, `Retry-After`, and explicit prohibition. No login, CAPTCHA bypass, third-party directory crawl, or automatic bulk refresh. These are operational choices derived from the crawler standard and Vercel's metered, bounded functions, not provider guarantees. [RFC 9309](https://www.rfc-editor.org/info/rfc9309/), [Vercel limits](https://vercel.com/docs/functions/limitations).

**Inference.** Use server-side `fetch` with timeouts, byte limits, redirect limits, and URL validation before each redirect (prevent private-network/metadata-service SSRF). Parse `schema.org`/JSON-LD (`LocalBusiness`, `Offer`, `PostalAddress`) and visible HTML text first; use a DOM library such as `cheerio` and optionally Mozilla Readability for longer pages. Readability needs a DOM in Node and warns that untrusted output needs sanitizing; it does not execute site JavaScript by default. A vendor page may omit prices or units: save **Listed price** only with exact amount, currency, unit, source URL and date seen; otherwise leave that field absent and request a Quote. [Readability README](https://github.com/mozilla/readability), [Schema.org LocalBusiness](https://schema.org/LocalBusiness), [Schema.org Offer](https://schema.org/Offer).

**Observation and inference on rights.** Indian law reserves reproduction and public communication of protected works; a factual amount, telephone number or address is a narrower reuse than copying prose or photographs, but a source link does not grant image rights. An `og:image` URL may describe a preview image, not license its reuse. Prefer a card with link/title and a neutral generated visual; obtain Vendor permission or an applicable license before copying a photograph. Browser hotlinking still displays the Vendor's work and can break via anti-hotlink controls; label and link to the source if used after rights review. Do not persist search-engine thumbnails. [Indian Copyright Act, §14](https://copyright.gov.in/Copyright_Act_1957/chapter_iii.html), [copyright handbook](https://copyright.gov.in/Documents/handbook.html), [Serper third-party rights](https://serper.dev/terms).

**JS-rendered pages.** Basic HTTP parsing misses content populated only in the browser. A headless browser would add Chrome packaging, CPU, memory and function-time cost on Vercel (250 MB compressed-function size, bounded memory/duration); use a hosted renderer only for eligible pages where static fetch fails. Firecrawl renders JavaScript and offers 1,000 free credits/month, one basic scrape per credit; its free plan has two concurrent requests, and terms need commercial-use review. Jina Reader offers unauthenticated basic use at 20 RPM or a free key at 500 RPM and 10 million initial tokens, but it cannot bypass blocked websites. Neither service overrides the Vendor's robots/terms or licenses its content for photos. [Vercel limits](https://vercel.com/docs/functions/limitations), [Firecrawl pricing](https://www.firecrawl.dev/pricing), [Firecrawl terms](https://www.firecrawl.dev/terms-of-service), [Jina Reader](https://jina.ai/reader/).

## 3. Geocoding a Vendor address into a stored Marker

These are forward-geocoding products, not substitutes for verifying a Vendor's address on its own site. Open-data products can place results on a Leaflet/OSM map, subject to provider and underlying-data attribution. No primary source reviewed supplies a credible comparative accuracy test of Indian wedding/event Vendor addresses. OpenCage warns that crowd-sourced coverage varies even between neighboring streets; Geoapify documents Indian PIN formats but does not thereby prove address-level match quality. ## Implementation boundary and verification needed before launch

1. Search only on a Member request. Query category + city/area + "official website" with an India locale; exclude known wedding directories from automated fetch and offer link-out only. Treat search snippets as candidate pointers. [Serper locale controls](https://serper.dev/), [Serper third-party rights](https://serper.dev/terms).
2. For each allowed Vendor-owned URL, fetch the live page, extract factual card fields, and save each field's source URL and date seen. Show a Listed price only if the site states currency and unit; do not transform a range or package headline into a firm Quote. Use a generic card image unless reuse is licensed. [Schema.org Offer](https://schema.org/Offer), [Indian copyright rights](https://copyright.gov.in/Copyright_Act_1957/chapter_iii.html).
3. Forward-geocode only an independently sourced address. Reject low-confidence/city-level results as precise Marker locations, and let the Member correct the Marker. Retain Geoapify and OSM credits near displayed location/map. [Geoapify API](https://apidocs.geoapify.com/docs/geocoding/forward-geocoding/), [Geoapify attribution](https://www.geoapify.com/geocoding-api/).
4. Before shipping, manually compare a small representative set of Indian Vendor-owned sites and addresses across major and smaller cities. Record own-site hit rate, page fetch success, address-level match rate, and false-positive rate. **No such quality test was run for this report.** OpenCage itself notes that country-level coverage scores do not replace testing on one's own addresses. [coverage note](https://blog.opencagedata.com/post/geocoding-coverage-report).
